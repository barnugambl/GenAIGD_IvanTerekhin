## Лучший вариант и почему

**Выбран:** Вариант 2

**Причины:**
1. Баланс между контролем и креативностью: модель следует промпту, но добавляет интересные детали
2. Читаемая архитектура + атмосфера, соответствующая проекту (минимализм, приглушённые тона)
3. `clip_l` с ключевыми тегами предотвращает "утечку" стиля в посторонние жанры
4. Разрешение 1344×768 даёт кинематографичный кадр

## Шаг 1. Формулировка промптов под архитектуру Flux Dev

**Контекст:**
- Хотел получить стабильный, воспроизводимый визуальный язык для локации «Архив Памяти».
- Для определения структуры запросов, которая будет использоваться во всех дальнейших ассетах проекта.

**Что пробовал:**
- Вариант 1: Теговый промпт (`archive, floating crystals, minimalist, cinematic, 8k`). Модель выдавала абстрактные формы, композиция «плыла», стиль дрейфовал в стандартный sci-fi.
- Вариант 2: Перегруженный поэтичный текст с метафорами. Flux терял архитектурную логику, добавлял нежелательные фантазийные детали, свет становился хаотичным.
- Вариант 3: Структурированный естественный язык. `t5xxl` - полное описание сцены, геометрии, освещения и настроения. `clip_l` - только якорные теги (`brutalist architecture, volumetric lighting, memory shards`).

**Вывод:**
- Принимал Вариант 3 как стандарт для проекта.
- Flux Dev не работает с тегами через запятую: ему нужны связные предложения в `t5xxl`. `clip_l` выполняет роль стилистического ограничителя, а не основного промпта.
- Далее: применить эту схему к генерации персонажей и пропсов, протестировать `guidance=4.0` для усиления контроля над композицией без потери атмосферы.

## Шаг 6. Multi-prompt workflow для серии персонажа

**Контекст:**
- Цель: собрать стабильную серию Доктора Елены Вороновой через multi-prompt, где identity остаётся постоянным, а меняется только состояние персонажа.
- Workflow: [workflows/w06_multiprompt.json](../workflows/w06_multiprompt.json)
- Selected: [outputs/selected/hw6/](../outputs/selected/hw6/)

**Фиксировали:**

| Параметр            | Значение                                        |
| ------------------- | ----------------------------------------------- |
| Модель              | `flux1-dev.safetensors`                         |
| CLIP / T5           | `clip_l.safetensors` + `t5xxl_fp16.safetensors` |
| VAE                 | `ae.safetensors`                                |
| Seed baseline       | `123456789`                                     |
| Размер output       | `941x1672`, вертикальный портрет                |
| Steps               | `35`                                            |
| CFG                 | `1.0`                                           |
| Sampler / Scheduler | `euler` / `simple`                              |
| Denoise             | `1.0`                                           |

**Prompt-блоки:**

| Блок | Роль | Текст |
| --- | --- | --- |
| constants / identity | Фиксирует героя | `Doctor Elena Voronova, elderly female scientist, fragile stooped silhouette, deeply tired eyes, natural aged face, old faded beige laboratory coat, wrinkled turtleneck, ash gray short hair, melancholic mentor, same character identity` |
| style / world | Фиксирует визуальный язык | `warm surrealism, sepia and ivory palette, old paper texture, soft diffused bloom, cinematic dust, melancholic memory archive, painterly semi-realism, beautiful decay, Tarkovsky and restrained Beksinski mood` |
| modifier / state | Меняет состояние кадра | Эмоция, ракурс, аксессуар, свет или эффект распада |

**Проверка весов modifier:**

Диапазон теста: `0.50–1.15` в `ConditioningAverage`. В сохранённом workflow оставлен вес `1.00`: он даёт читаемое состояние, но ещё не полностью перебивает identity-блок.

| Вариант | Seed | Weight / Strength | Что меняли | Что изменилось | Keep / Drop |
| --- | --- | --- | --- | --- | --- |
| 01 base | `123456789` | `1.00` | Нейтральная эмоция, прямой портрет | Лицо и силуэт стабильные, хороший базовый кадр для сравнения | Keep |
| 02 alert | `123456789` | `0.75` | Эмоция: тревога + поворот на сигнал | Появилось напряжение, но возраст, халат и причёска сохранились | Keep |
| 03 exhausted | `123456789` | `0.85` | Состояние: усталость, посадка за столом, тёплая лампа | Сильнее изменилось окружение и поза, персонаж всё ещё узнаётся | Keep |
| 04 fragmented | `123456789` | `1.00` | Состояние: распад памяти, трещины, частицы | Эффект распада читается, но лицо остаётся достаточно стабильным | Keep |
| 05 determined | `123456789` | `0.90` | Аксессуар: ключ-карта, более решительный взгляд | Аксессуар добавил сюжетную функцию, не сломал дизайн костюма | Keep |

| test drop | `123456789` | `1.15` | Слишком сильный modifier: драматичный свет + распад + аксессуар одновременно | Начинает плыть лицо, возраст и силуэт; кадр выглядит как другой персонаж | Drop |

**Вывод:**
- Рабочий диапазон веса modifier: примерно `0.75–1.00`.
- Самый стабильный baseline: `1.00`, как в сохранённом workflow. Для более мягких состояний можно опускаться до `0.75–0.85`, чтобы modifier не переписывал identity.
- На узнаваемость сильнее всего влияют: возраст лица, короткие седые волосы, старый бежевый лабораторный халат, сутулый силуэт и приглушённая сепия.
- Consistency ломается, когда одновременно усиливаются несколько осей: сильная эмоция + новый свет + аксессуар + эффект распада. В таких тестах модель начинает менять лицо и костюм.
- Дальше оставляю baseline: fixed seed `123456789`, identity/style без изменений, modifier weight `1.00` в workflow, а для мягких эмоциональных вариантов — `0.75–0.90`.

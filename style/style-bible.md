# Style Bible: Echoes of the Departed

## 1. Art Goal
Проект должен вызывать у игрока **"меланхоличное любопытство"** — смесь грусти, трепета и острого желания узнать правду. Главное ощущение — **"красивый распад"**, где воспоминания рассыпаются, оставляя после себя эхо.

## 2. Chosen baseline
**Baseline: Теплый сюрреализм (Direction B)**
- Почему: Для нарратива о памяти и потерянных жизнях "холодный" техногенный стиль делает Архив безличной машиной. "Теплый" стиль очеловечивает потерю, добавляет трагизма и красоты.

## 3. Style Rules

| Правило | Описание |
|---------|----------|
| Палитра | Приглушенные тона: сепия, беж, цвет слоновой кости, выцветший бордовый |
| Материалы | Старая бумага, пыль, дымка, ржавый металл, потрескавшаяся краска |
| Свет | Мягкий, рассеянный, с эффектом свечения (bloom), тени не черные |
| Камера | От первого лица, плавная, в моменты распада — эффект старой пленки |
| Стилизация | Полу-реализм с живописным уклоном, формы теряют четкость на краях |
| Читаемость | Ключевые объекты выделены композицией, "шум" не скрывает подсказки |
| Вариативность | Содержание меняется, но обработка (цвета, зернистость) едина |

## 4. Bans / Запреты
-  Яркие неоновые цвета (RGB, Cyan, Magenta)
- Чистые глянцевые поверхности (зеркала, пластик)
-  Гротескное насилие в визуалах
- Симметрия и идеальные геометрические формы

## 5. Hero Baseline — Doctor Elena Voronova

Базовый персонаж для текущей визуальной серии — Доктор Елена Воронова. Подробная карточка: [characters/hero.md](../characters/hero.md). Константы: [design/constants.md](../design/constants.md). Selected-серия: [outputs/selected/hw6/](../outputs/selected/hw6/).

| Область | Что удерживать |
| --- | --- |
| Силуэт | Пожилая хрупкая фигура, узкие плечи, лёгкая сутулость |
| Голова / лицо | Короткие седые волосы, естественные морщины, глубоко посаженные усталые глаза |
| Костюм | Старый бежевый лабораторный халат, тёмная мятая водолазка или высокий ворот |
| Палитра | Сепия, слоновая кость, пепельный серый, тусклый янтарный свет |
| Подача | Средний или средне-крупный портрет, лицо и верх халата читаются |

**Запреты для героя:**
- Не омолаживать лицо и не сглаживать кожу.
- Не менять короткие седые волосы на длинную или яркую причёску.
- Не заменять халат на броню, скафандр, новый медицинский костюм или деловой пиджак.
- Не добавлять яркий макияж, глянцевые sci-fi аксессуары, импланты или неон.
- Не превращать распад памяти в кровь, телесный хоррор или агрессивный красный свет.

## Reference rules

### Что переносим из референсов

- Палитра: приглушённая сепия, слоновая кость, пепельный серый, тусклый amber-свет, выцветший бордовый только как акцент.
- Свет: мягкий рассеянный bloom, пыль в воздухе, не-чёрные тени, ощущение старой плёнки.
- Композиция: глубокая перспектива Архива, readable foreground / midground / background, ясный фокус на memory shard или лице персонажа.
- Материалы: старая бумага, пыль, потрескавшаяся краска, worn concrete, матовая ткань, хрупкое стекло / кристалл.
- Настроение: меланхоличное любопытство, тихая тревога, "красивый распад", ощущение найденного слишком поздно воспоминания.
- Поза / силуэт: хрупкая сутулость Вороновой, сдержанные жесты, отсутствие героического экшен-силуэта.
- Камера / ракурс: первый-person для скрингенов Архива, средний или средне-крупный портрет для Вороновой, без клипового динамичного экшена.

### Что не копируем

- Узнаваемых персонажей: не переносить лица, костюмы и силуэты конкретных героев из игр / фильмов.
- Логотипы и бренды: не использовать чужие знаки, интерфейсы, шрифтовые марки и фирменную символику.
- Лицо реального человека: не копировать портреты актёров, преподавателей, авторов референсов или случайных людей.
- Уникальный дизайн чужого IP: не повторять один-в-один Обра Динн, Edith Finch, Outer Wilds, Beksiński-композиции или кадры Тарковского.
- Точную форму костюма / символику: у Вороновой должен оставаться свой старый лабораторный халат, а не чужой узнаваемый дизайн.
- Композицию один в один, если она слишком узнаваема: референс даёт принцип, а не готовую раскладку кадра.

### Как проверяем результат

- Ассет поддерживает GDD: показывает смерть / память / расследование / Архив, а не случайный красивый sci-fi.
- Ассет совпадает со style bible: палитра, материалы, свет и уровень распада остаются в baseline.
- Из рефа перенесены только отдельные качества: свет, материал, настроение, поза или композиционный принцип.
- Результат не выглядит копией: нет узнаваемого персонажа, кадра, логотипа, уникального костюма или прямого IP-заимствования.
- Изображение можно использовать для Midterm / Final: оно читается как игровой ассет, а не как тестовый арт без роли в проекте.

# ControlNet Prep — W07 to W08

## 1. Что нужно контролировать

| Что контролировать | Почему важно для проекта | Где сейчас плывёт |
| --- | --- | --- |
| Глубина Архива | Хаб строится на многоэтажных галереях и центральной пустоте; если глубина ломается, кадр перестаёт быть игровым пространством | Дальние балконы и подвесные платформы могут терять масштаб после `outpaint` |
| Контур memory shard | Шард должен читаться как интерактивный объект, а не случайная лампа | После локальных правок форма объекта может становиться слишком мягкой |
| Поза персонажа в сцене | В следующих кадрах нужно поставить Воронову или Архивариуса внутрь Архива без потери силуэта | Без контроля персонаж может закрыть ключевой объект или сломать масштаб окружения |

## 2. Подходящий тип ControlNet

| Тип | Для чего использовать | Что должен удержать |
| --- | --- | --- |
| `depth` | Основной контроль для Архива | Перспективу галерей, расстояние между платформами, центральную вертикальную пустоту |
| `canny` | Для локального объекта / shard | Чистый контур glowing shard, край платформы, читаемую форму интерактивного объекта |
| `pose` | Для будущего кадра с персонажем | Сутулый силуэт Вороновой, положение рук близко к корпусу, масштаб человека относительно хаба |

## 4. План следующей проверки

1. Взять `05-w07-outpaint-after.png` как base для `depth`.
2. Проверить, удерживает ли `depth` масштаб галерей и центральную пустоту.
3. Для foreground shard отдельно протестировать `canny`, чтобы объект был читаемым.
4. Если добавляется Воронова, использовать `pose` только для силуэта и позы, а style/identity держать через `characters/hero.md` и `design/constants.md`.

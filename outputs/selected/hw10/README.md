## Style notes

- Палитра: сепия, слоновая кость, пепельный серый, тусклый янтарный свет.
- Материалы: старая бумага, пыль, мутное стекло, ржавый металл, потрескавшиеся поверхности.
- Настроение: меланхоличное любопытство, тихая тревога, красивый распад.
- Запреты соблюдены: без неона, глянцевого sci-fi, крови, гротескного хоррора и прямого копирования чужого IP.
